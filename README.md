# Namma Platform 🚆

Namma Platform is a Kannada-first railway station assistant Android application built using Kotlin and Jetpack Compose.

## 📌 Project Overview
This app helps railway passengers in small railway stations by displaying:
- Platform numbers
- Train arrival timings
- Coach sequence layouts
- Kannada voice announcements

The application is designed to improve passenger convenience and provide regional language accessibility.

---

## ✨ Features
- Station selection dropdown
- Dynamic train list
- Platform information
- Coach layout visualization
- Kannada Text-to-Speech announcements
- Modern Material 3 UI
- Responsive Android design

---

## 🛠️ Technologies Used
- Kotlin
- Jetpack Compose
- Android Studio
- Material 3
- TextToSpeech API
- MVVM Architecture

---

## 🚉 Supported Stations
- Mysuru
- Mandya
- Hassan
- Shivamogga
- Bengaluru

---

## 📱 Screens
- Splash Screen
- Home Screen
- Train Details Screen
- Settings Screen

---

## 🎯 Objective
To create a smart and accessible railway assistant application focused on Kannada-speaking passengers and small railway stations.
